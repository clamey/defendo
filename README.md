# Defendo

A 70s retro space-monster board game, as a browser tower defense.

Pick your biotype — **Human Space Warriors** or **Space Monsters** — and hold your tower against waves of the other side. After each wave: (1) upgrade the tower or build a mechanism, then (2) place a terrain tile.

## Run

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests + headless auto-play sim
npm run typecheck
npm run build      # static site in dist/
```
